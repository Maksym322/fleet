# Contributing

1. Fork, create a branch, make a focused change.
2. Run `python -m unittest discover -s tests` (Python 3.12+, git required; no network, no secrets).
3. Add a test for behavior changes. Keep docs in sync (README, docs/, CHANGELOG).
4. Never commit tokens, personal paths, hostnames or real task history. Use synthetic fixtures.
5. Open a pull request describing the change and how you verified it.
